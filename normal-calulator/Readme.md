## I've created a modern calculator with a sleek, contemporary design featuring:
### Design Features:

Beautiful gradient backgrounds with purple/violet theme
Glass-morphism effect with backdrop blur
Smooth hover animations and transitions
Responsive design that works on mobile and desktop
Clean, minimalist button layout
Dual-line display showing previous operation

### Functionality:

Basic operations: addition, subtraction, multiplication, division
Clear all (AC) and backspace (⌫) functions
Decimal point support
Keyboard support (numbers, operators, Enter, Escape, Backspace)
Error handling for division by zero

The calculator has a premium feel with gradient buttons and smooth interactions. Try hovering over the buttons to see the nice scale effects!
