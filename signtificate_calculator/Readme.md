## I've created a fully functional scientific calculator with a modern, sleek design. Here's what it includes:
# Features:

Basic Operations: Addition, subtraction, multiplication, division
Scientific Functions: sin, cos, tan, log, ln, square root
Advanced Features: Power (x^y), factorial, square, inverse (1/x)
Constants: π (pi) and e
Angle Modes: Toggle between degrees (DEG) and radians (RAD)
Expression Support: Parentheses for complex calculations
Utilities: Clear (AC), delete (DEL), sign toggle (+/-)

## Design Highlights:

Dark theme with gradient purple background
Color-coded buttons (numbers, operators, functions)
Responsive grid layout
Smooth hover animations
Error handling with visual feedback
Display shows both current and previous operations
